อธิบาย Algorithms

1. Random Local Search (RLS)

แนวคิด: ง่ายที่สุด - สุ่มขยับตำแหน่ง ถ้าดีกว่าเดิมก็รับ 

for each iteration:
    new_pos = current_pos + random_noise
    if fitness(new_pos) < fitness(current_pos):
        current_pos = new_pos

2. Genetic Algorithm (GA)

แนวคิด: จำลองวิวัฒนาการ - Selection, Crossover, Mutation 

for each generation:
    1. Selection: เลือกตัวที่ fitness ดี
    2. Crossover: ผสม genes → child = α*parent1 + (1-α)*parent2
    3. Mutation: เปลี่ยนแปลง genes แบบสุ่ม

3. Grasshopper (GOA)

แนวคิด: จำลองพฤติกรรมตั๊กแตน - ผลัก/ดึงดูด + Target 

Social Force: s(r) = f*exp(-r/l) - exp(-r)
  - ใกล้กัน → ผลักกัน
  - ห่างกัน → ดึงดูด

Position: X_new = c * [Social Forces] + Target
  - c ลดลงตาม iteration (exploration → exploitation)
