## 1. GOA คืออะไร?

**GOA (Grasshopper Optimisation Algorithm)** = วิธีการหาคำตอบที่ดีที่สุด โดยเลียนแบบพฤติกรรมของ **ฝูงตั๊กแตน**

### เปรียบเทียบง่ายๆ:
```
สมมติคุณหลงอยู่ในป่า และต้องหาทางออก (จุดที่ต่ำที่สุด)

วิธีธรรมดา: เดินไปเรื่อยๆ หวังว่าจะเจอ → อาจติดอยู่ในหลุมเล็กๆ

วิธี GOA: ส่งตั๊กแตน 30 ตัวไปสำรวจพร้อมกัน
         → ตัวไหนเจอที่ต่ำสุด บอกตัวอื่น
         → ทุกตัวค่อยๆ เข้าหาจุดนั้น
         → เจอทางออกจริงได้เร็วกว่า!
```

## 2. ใช้ทำอะไรได้บ้าง?

### 2.1 ปัญหาที่ GOA แก้ได้

| ประเภทปัญหา | ตัวอย่าง |
|-------------|----------|
| **หาค่าที่ดีที่สุด** | หาราคาขายที่ได้กำไรสูงสุด |
| **ลดต้นทุน** | ออกแบบโครงสร้างที่ใช้วัสดุน้อยที่สุด |
| **หาเส้นทาง** | หาเส้นทางขนส่งที่สั้นที่สุด |
| **ปรับแต่งค่า** | หาค่า parameter ที่ดีที่สุดสำหรับ AI |
| **จัดตารางงาน** | จัดตารางพนักงานให้มีประสิทธิภาพสูงสุด |

### 2.2 ตัวอย่างการใช้งานจริงใน Paper

#### ตัวอย่างที่ 1: ออกแบบโครงเหล็ก (Truss)
```
ปัญหา: ต้องการสร้างโครงเหล็กรับน้ำหนักได้ แต่ใช้เหล็กน้อยที่สุด

สิ่งที่ต้องหา: ขนาดของแท่งเหล็กแต่ละชิ้น

GOA ช่วย: หาขนาดที่พอดี → ประหยัดเหล็ก → ประหยัดเงิน
```

#### ตัวอย่างที่ 2: ออกแบบคานยื่น (Cantilever Beam)
```
ปัญหา: คานยื่น 5 ส่วน ต้องรับน้ำหนักได้ แต่เบาที่สุด

สิ่งที่ต้องหา: ขนาดของแต่ละส่วน

GOA ช่วย: หาสัดส่วนที่ดีที่สุด
```

## 3. หลักการทำงาน (อธิบายง่ายๆ)

### 3.1 เลียนแบบตั๊กแตนยังไง?

```
🦗 ตั๊กแตนในธรรมชาติ:
   - อยู่ใกล้กันเกินไป → ผลักกันออก (ไม่ชนกัน)
   - อยู่ห่างกันพอดี → ดึงดูดเข้าหากัน (อยู่เป็นฝูง)
   - เคลื่อนที่ไปหาอาหาร (เป้าหมาย)

🖥️ GOA ในคอมพิวเตอร์:
   - "ตั๊กแตน" = คำตอบที่เป็นไปได้
   - "อาหาร" = คำตอบที่ดีที่สุดที่หาเจอ
   - ตั๊กแตนทุกตัวค่อยๆ เข้าใกล้อาหาร
```

### 3.2 ขั้นตอนการทำงาน

```
ขั้นที่ 1: สร้างตั๊กแตน 30 ตัว (สุ่มคำตอบ 30 ชุด)
          ↓
ขั้นที่ 2: ดูว่าตัวไหนอยู่ใกล้อาหารที่สุด (คำตอบไหนดีที่สุด)
          ↓
ขั้นที่ 3: ตั๊กแตนทุกตัวเคลื่อนที่
          - ผลักกันเพื่อสำรวจพื้นที่ใหม่
          - ดึงดูดเข้าหาตัวที่ดีที่สุด
          ↓
ขั้นที่ 4: อัปเดตตำแหน่งอาหาร (ถ้าเจอที่ดีกว่า)
          ↓
ขั้นที่ 5: ทำซ้ำขั้นที่ 2-4 จนครบ 500 รอบ
          ↓
ขั้นที่ 6: ได้คำตอบที่ดีที่สุด!
```

## 4. วิธีใช้งาน GOA

### 4.1 สิ่งที่ต้องเตรียม

```
1. ฟังก์ชันที่ต้องการหาค่าต่ำสุด/สูงสุด
2. ขอบเขตของคำตอบ (ค่าต่ำสุด-สูงสุดที่เป็นไปได้)
3. จำนวนตัวแปร (กี่มิติ)
```

### 4.2 ตัวอย่างโค้ด Python แบบง่ายที่สุด

```python
import numpy as np

# ============================================
# ขั้นที่ 1: กำหนดปัญหาของคุณ
# ============================================

def my_problem(x):
    """
    ฟังก์ชันที่ต้องการหาค่าต่ำสุด
    x = ตัวแปรที่ต้องหา (เป็น array)

    ตัวอย่าง: หาจุดต่ำสุดของ x² + y²
    คำตอบที่ถูกต้อง: x=0, y=0 (ค่าต่ำสุด = 0)
    """
    return sum(x**2)  # x² + y² + z² + ...


# ============================================
# ขั้นที่ 2: ตั้งค่า GOA
# ============================================

# จำนวนตั๊กแตน (คำตอบที่ลองพร้อมกัน)
num_grasshoppers = 30

# จำนวนรอบการค้นหา
max_iterations = 100

# จำนวนตัวแปร (มิติ)
num_variables = 2  # เช่น x และ y

# ขอบเขตของคำตอบ
lower_bound = -100  # ค่าต่ำสุดที่เป็นไปได้
upper_bound = 100   # ค่าสูงสุดที่เป็นไปได้


# ============================================
# ขั้นที่ 3: รัน GOA
# ============================================

def run_GOA():
    # สร้างตั๊กแตนแบบสุ่ม
    grasshoppers = np.random.uniform(
        lower_bound, upper_bound,
        (num_grasshoppers, num_variables)
    )

    # หาตัวที่ดีที่สุด
    fitness = [my_problem(g) for g in grasshoppers]
    best_idx = np.argmin(fitness)
    target = grasshoppers[best_idx].copy()
    target_fitness = fitness[best_idx]

    # ค่าคงที่
    cMax, cMin = 1, 0.00001
    f, l = 0.5, 1.5

    # วนลูปหาคำตอบ
    for iteration in range(max_iterations):
        # คำนวณ c (ลดลงเรื่อยๆ)
        c = cMax - iteration * (cMax - cMin) / max_iterations

        # อัปเดตตำแหน่งทุกตัว
        for i in range(num_grasshoppers):
            new_pos = np.zeros(num_variables)

            for j in range(num_grasshoppers):
                if i != j:
                    # คำนวณระยะห่าง
                    dist = np.abs(grasshoppers[j] - grasshoppers[i])
                    dist = np.clip(dist, 1, 4)  # จำกัดระยะใน [1,4]

                    # คำนวณแรงทางสังคม
                    s = f * np.exp(-dist/l) - np.exp(-dist)

                    # ทิศทาง
                    direction = np.sign(grasshoppers[j] - grasshoppers[i])

                    # สะสมแรง
                    new_pos += c * s * direction

            # อัปเดตตำแหน่ง (เข้าหา target)
            grasshoppers[i] = c * new_pos + target

            # ตรวจสอบขอบเขต
            grasshoppers[i] = np.clip(grasshoppers[i], lower_bound, upper_bound)

        # อัปเดต target ถ้าเจอที่ดีกว่า
        fitness = [my_problem(g) for g in grasshoppers]
        best_idx = np.argmin(fitness)
        if fitness[best_idx] < target_fitness:
            target = grasshoppers[best_idx].copy()
            target_fitness = fitness[best_idx]

        # แสดงความคืบหน้า
        if iteration % 20 == 0:
            print(f"รอบที่ {iteration}: ค่าที่ดีที่สุด = {target_fitness:.6f}")

    return target, target_fitness


# ============================================
# ขั้นที่ 4: รันและดูผลลัพธ์
# ============================================

best_solution, best_value = run_GOA()
print(f"\n=== ผลลัพธ์ ===")
print(f"คำตอบที่ดีที่สุด: {best_solution}")
print(f"ค่าต่ำสุดที่หาได้: {best_value}")
```

### 4.3 ผลลัพธ์ที่คาดหวัง

```
รอบที่ 0: ค่าที่ดีที่สุด = 1234.567890
รอบที่ 20: ค่าที่ดีที่สุด = 45.678901
รอบที่ 40: ค่าที่ดีที่สุด = 2.345678
รอบที่ 60: ค่าที่ดีที่สุด = 0.123456
รอบที่ 80: ค่าที่ดีที่สุด = 0.001234

=== ผลลัพธ์ ===
คำตอบที่ดีที่สุด: [0.001, -0.002]  ← ใกล้ 0 มาก!
ค่าต่ำสุดที่หาได้: 0.000005        ← ใกล้ 0 มาก!
```

## 5. ใช้กับปัญหาของตัวเองยังไง?

### ขั้นตอนง่ายๆ 3 ขั้น:

### ขั้นที่ 1: แปลงปัญหาเป็นฟังก์ชัน

```python
# ตัวอย่าง: หาจุดที่ทำให้กำไรสูงสุด
# ตัวแปร: ราคาขาย (x[0]) และ จำนวนผลิต (x[1])

def calculate_profit(x):
    price = x[0]      # ราคาขาย
    quantity = x[1]   # จำนวนผลิต

    revenue = price * quantity           # รายได้
    cost = 10 * quantity + 1000          # ต้นทุน
    profit = revenue - cost              # กำไร

    return -profit  # ใส่ลบเพราะ GOA หาค่าต่ำสุด
                    # (หาค่าต่ำสุดของ -กำไร = หาค่าสูงสุดของกำไร)
```

### ขั้นที่ 2: กำหนดขอบเขต

```python
# ราคาขาย: 1-1000 บาท
# จำนวนผลิต: 1-10000 ชิ้น

lower_bound = [1, 1]
upper_bound = [1000, 10000]
num_variables = 2
```

### ขั้นที่ 3: รัน GOA และได้คำตอบ

```python
best_solution, best_value = run_GOA()

print(f"ราคาขายที่ดีที่สุด: {best_solution[0]:.2f} บาท")
print(f"จำนวนผลิตที่ดีที่สุด: {best_solution[1]:.0f} ชิ้น")
print(f"กำไรสูงสุด: {-best_value:.2f} บาท")
```

## 6. ค่าที่ต้องปรับ (Parameters)

| Parameter | ค่าแนะนำ | ความหมาย |
|-----------|----------|----------|
| `num_grasshoppers` | 20-50 | จำนวนคำตอบที่ลองพร้อมกัน (มาก = ละเอียด แต่ช้า) |
| `max_iterations` | 100-500 | จำนวนรอบ (มาก = แม่นยำ แต่ช้า) |
| `cMax` | 1 | ค่าเริ่มต้นของ c (ไม่ต้องเปลี่ยน) |
| `cMin` | 0.00001 | ค่าสุดท้ายของ c (ไม่ต้องเปลี่ยน) |
| `f` | 0.5 | ความเข้มของแรงดึงดูด (ไม่ต้องเปลี่ยน) |
| `l` | 1.5 | ระยะของแรงดึงดูด (ไม่ต้องเปลี่ยน) |

## 7. ข้อดี-ข้อเสียของ GOA

### ข้อดี
- ใช้ง่าย ไม่ต้องรู้คณิตศาสตร์ลึก
- หาคำตอบได้แม้ไม่รู้โครงสร้างของปัญหา
- หลีกเลี่ยงการติดอยู่ในคำตอบที่ไม่ดี
- ใช้ได้กับปัญหาหลากหลายประเภท

### ข้อเสีย
- ไม่รับประกันว่าจะได้คำตอบที่ดีที่สุด 100%
- ต้องรันหลายรอบเพื่อความมั่นใจ
- ช้ากว่าวิธีทางคณิตศาสตร์ (ถ้าปัญหาง่าย)

## 8. เมื่อไหร่ควรใช้ GOA?

### ควรใช้เมื่อ:
- ปัญหาซับซ้อน มีหลายตัวแปร
- ไม่รู้สูตรคณิตศาสตร์ของปัญหา
- ต้องการคำตอบที่ "ดีพอ" ไม่ต้องสมบูรณ์แบบ
- มีเวลาให้โปรแกรมรันสักพัก

### ไม่ควรใช้เมื่อ:
- ปัญหาง่ายๆ มีสูตรตรงๆ
- ต้องการคำตอบทันที
- ต้องการคำตอบที่แม่นยำ 100%
